Privacy Policy

Last updated: November 9, 2026

This policy covers the Bigonomics uploader, a private tool used only by the operator of the Bigonomics channels to manage the operator's own YouTube channels. It is not offered to the public.

What it accesses

With the operator's permission through Google sign-in, the tool uploads videos, sets thumbnails, schedules or changes the visibility of videos, edits titles and descriptions, and reads view counts and analytics for the operator's own YouTube channels (YouTube Data API and YouTube Analytics API).

This tool uses YouTube API Services. By using it, the operator agrees to the YouTube Terms of Service. See also the Google Privacy Policy.

How data is stored and used

Sign-in tokens are stored only on the operator's own computer. Channel statistics are stored on the operator's computer and in the operator's private dashboard, and are processed with an AI assistant (Anthropic Claude) acting as a service provider, only to run the operator's own channels. They are not sold, not used for advertising, and not shared with anyone else. The tool does not collect data about viewers or other users.

The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

Tokens are kept until access is revoked. Channel statistics are refreshed regularly while access is authorized, and authorization is re-checked at least every 30 days. If access is revoked, tokens are deleted immediately and stored YouTube data is deleted within 30 days. Access can be revoked at any time at Google security settings (security.google.com/settings/security/permissions).
